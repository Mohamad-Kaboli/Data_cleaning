Project Overview
Welcome to my first Data Analysis project! 
This project focuses purely on "Data Cleaning" and "Data Preprocessing" using Python. In the real world, data is rarely clean and ready for analysis. The goal of this project is to demonstrate my ability to handle messy datasets, handle missing values, and prepare data for exploratory data analysis (EDA) or Machine Learning models.

Tools & Technologies Used
- Python 3.x
- Pandas: For data manipulation and aggregation.
- NumPy: For numerical operations.
- Matplotlib & Seaborn: For basic visualization to detect outliers.
- Jupyter Notebook: As the development environment.

Key Data Cleaning Steps Performed
1. Importing & Inspecting Data: Loading the dataset and understanding its structure (`.info()`, `.describe()`).
2. Handling Missing Values (Imputation/Removal): Identifying `NaN` values and deciding whether to drop or fill them based on the context (e.g., using mean, median, or mode).
3. Removing Duplicates: Checking for and dropping duplicated records to ensure data integrity.
4. Standardizing Data Formats: Converting data types (e.g., strings to datetime objects) and fixing inconsistencies in categorical features.
5. Handling Outliers: Detecting extreme values using statistical methods or boxplots and treating them logically.
6. Feature Renaming: Renaming columns to follow a standard naming convention (snake_case) for easier querying.

How to Run
1. Clone this repository to your local machine.
2. Ensure you have Python installed along with the required libraries (`pandas`, `numpy`).
3. Open the `Data_Cleaning_Project.ipynb` notebook.
4. Run the cells step-by-step to see the transformation from raw data to clean data.
